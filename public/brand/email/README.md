# ResQ email signature wordmark

Use resq-wordmark.png for a transparent background, or resq-wordmark-white.png for a white background. Both are 351 x 249 pixels. Display at approximately 120 pixels wide with proportional height.

The artwork matches the navbar title: local Oswald variable font at weight 600, navy #043473, gold dot #e4d076, and the same proportional letter spacing. Text is rendered into PNG pixels, so recipients do not need the font.

Insert the PNG using the image button in your signature editor beneath your name and title. If an alternative-text field is available, enter ResQ. Save your signature.
